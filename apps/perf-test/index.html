Each test case opens a minimal page that loads the player + media element via the packages/html/cdn/ bundles. The on-page overlay reports page load, player init, and first-frame timing; capture Bundle Transfer Size from the DevTools Network tab.

TC-06 · Bundled SPF + hls.light · TS

Same architecture as TC-03 with hls.light in place of the full HLS.js. The dual-hls-light-video bundle aliases hls.js to hls.js/light at build time. Bundled counterpart to TC-08.

TC-07 · Sequenced lazy · SPF → HLS.js (TS path)

SPF media element mounts. After a 20 ms mocked format-detection endpoint, the page dynamically imports the full hls-video bundle and swaps in <hls-video> for TS playback. Captures four performance.mark() phases.
